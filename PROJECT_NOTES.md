# Polymarket Companion

A prediction-market hedging / helper companion tool.

**The idea:** Ask "what are the best plays today?" and get back where the tool
perceives value — so you can hedge $50 (or whatever) without getting paralyzed
by the sheer number of markets on Polymarket.

## Direction (Handshake AI-builder project)
- Schema + API + MCP driven (higher-level architecture — the whole point is to master this).
- Companion / recommendation layer over Polymarket markets.
